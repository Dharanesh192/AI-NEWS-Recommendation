# 📰 AI News Recommendation System

A smart **AI-powered News Recommendation System** that analyzes user interests and suggests personalized news articles.  
Built using modern technologies with a clean UI and intelligent recommendation logic.

---

## 🧠 Project Overview

This project is designed to demonstrate how **AI-based recommendation systems** work in real-world applications.

The system:
- Analyzes user preferences
- Processes news datasets (CSV / API)
- Recommends relevant news articles
- Displays structured results visually

It is ideal for **students and beginners** who want to understand:
- Machine Learning basics
- Recommendation algorithms
- Data preprocessing
- Frontend + Backend integration

---

## 🛠️ Features

- 📰 Upload news by API 
- 🤖 AI Summarization concept by **Gemini** 
- 🔎 Category-based filtering
- ⚡ Fast news uploading
- 📁 Structured cards displaying NEWS 
- 🧠 Simple recommendation algorithm (content-based filtering)
- 🎨 Clean and interactive UI
- 📈 Expandable for real-time API integration

---

## 🧩 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python 
- **AI Logic:** Content-Based Filtering
- **Core Concept:** API  
- **Optional:** Electron (Desktop App Support)
